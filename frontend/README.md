# Vero — AI Workforce Allocation Platform

Vero is an AI-powered workforce allocation and negotiation platform that intelligently connects companies with skilled professionals in real time. Companies can post workforce requirements, while workers create verified professional profiles with skills, availability, experience, pricing, and certifications.

Using AI-driven matching, Vero analyzes compatibility, proximity, availability, qualifications, and budget preferences to recommend the best-fit professionals for every task. The platform also streamlines workforce operations through smart negotiation assistance, assignment management, analytics, and real-time operational insights — all within a modern enterprise-grade dashboard experience.

> **Note:** This repository currently contains the **Frontend** implementation. Backend integration is planned for the next phase of development.

## 🚀 Features

- **Intelligent Matching**: AI-driven compatibility analysis based on proximity, skills, and budget.
- **Enterprise Onboarding**: Specialized, validated flows for both Workers and Companies.
- **Brutalist Design System**: High-end, monochromatic, and responsive UI built for modern enterprise standards.
- **Real-time Insights**: Dynamic dashboard for managing workforce operations and analytics.
- **Secure Verification**: Integrated flows for identity and certification verification.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org) (App Router)
- **Library**: [React](https://reactjs.org)
- **Language**: [TypeScript](https://www.typescriptlang.org)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)
- **Animation**: [Framer Motion](https://www.framer.com/motion)
- **Form Management**: [React Hook Form](https://react-hook-form.com) + [Zod](https://zod.dev)
- **Design Tools**: [Figma](https://www.figma.com)

## 🏁 Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yuvrajnag/vero.git
   ```

2. Install dependencies:
   ```bash
   cd frontend
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
